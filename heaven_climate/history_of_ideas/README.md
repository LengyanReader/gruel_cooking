# history_of_ideas — Intellectual History

Tracing school genealogies and key turning points in astronomy and climate research.

## Intellectual Genealogies (Examples)

### Astronomy
- Ptolemy → Copernicus → Tycho → Kepler → Newton
- Herschel → Hubble → Lemaitre → Penzias & Wilson
- Einstein → de Sitter → Lambda-CDM model

### Climatology
- Fourier → Tyndall → Arrhenius → Keeling → IPCC
- Milankovitch → Hays → cyclostratigraphy
- Lorenz → chaos theory and climate prediction

## Record Format

Each genealogy includes:
- List of key figures (in chronological order)
- Each person's contribution and key papers
- How ideas passed from one person to the next
- Controversies and fork points
- References (primary sources preferred)
