# 织网库 · Concept Weave

<!-- zh -->
这里把**同一个概念、八种文明的说法**织成一张网：`概念 → 八语词位 → 词源 · 借词 · 镜像关系`。数据源是 Core Glossary（`data/core_glossary.json`，对应 README 附录 D 底表）。

- **概念轴**：每个概念（水、月、心、时、海、自由、茶、寂静、树、风、光、自然）从底表取八个高信号词位（zh/en/fr/ja/sa/la/de/sv），逐一挂到概念节点。
- **织线**：词源同根（印欧 *wédor → water/Wasser/vatten）、罗曼传承（eau ← aqua）、借词回旋镖（茶 东传西渡）、意象镜像（PIE *dī- → Zeit/tid）……
- **审校防线**：八语词位为高信号底表词，仍属**待母语审校**；织线中示意性条目已标注。

This is the weave of **one concept across eight civilizations**: concept → eight-language terms → etymological · loan · mirror relations. Data: Core Glossary (`data/core_glossary.json`, mirroring README Appendix D).

- **Concept axis**: each concept (water, moon, heart, time, sea, freedom, tea, silence, tree, wind, light, nature) carries eight high-signal baseline terms (zh/en/fr/ja/sa/la/de/sv), one per language, attached to the concept node.
- **Threads**: shared roots (PIE *wédor → water/Wasser/vatten), Romance descent (eau ← aqua), loan echoes (tea east- and west-bound), image mirrors (PIE *dī- → Zeit/tid)…
- **Review shield**: the eight-language terms are high-signal baselines, still **pending native review**; illustrative threads are marked.

Read it as a graph: concept is the hub, languages the spokes, etymology the cables between spokes.
