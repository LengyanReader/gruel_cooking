# academic_research · 前沿学术与科研方向研究

> 目的：为一个跨媒介、跨文明的知识工程（本仓库 `gruel_cooking`）寻找**下一步可以研究什么、和谁合作**。
> 本模块不是文献综述，而是一份**「方向 × 势能 × 可介入性」的侦察图**——服务开拓视野与发起跨学科合作两类用途。
>
> Companion to `discovery_atlas/` 的第五域 `science`：那一域登记「学术发现的**基础设施**」（arxiv、OpenAlex、Semantic Scholar、Quanta…「去哪儿找」）；本模块消化其产出，回答「**找什么、值不值得追、怎么切入**」。

---

## 一、范围 · Scope

覆盖用户点名的六条主轴，且优先关注它们**相互咬合**的地带：

1. **基础科学**（basic science）——物理、数学、生命科学前沿
2. **人工智能**（AI）——尤其是 AI-for-Science、推理与科学发现
3. **数据科学 / 计算科学**（data & computational science）
4. **跨学科**（interdiscipline）——学科间的方法迁移与新范式
5. **超学科**（transdiscipline）——学术系统与 societal 知识的共产（co-production）
6. **文化 / 文明 / 人文**（culture / civilization / humanities）——含数字人文、文化分析

**取向**：只要「正在生成、尚未固化」的方向。已成熟的教科书领域除非作为**交叉枢纽**，一律不列。

## 二、方法 · Method

沿用本仓库 discovery_atlas 已验证的纪律，逐条落到学术场景：

- **回源优先（M0.4 零臆造）**：每个方向、每位学者、每个机构归属，须有一手或权威来源支撑（官方站、Nature/Science、奖项公告、机构页、arXiv），不凭记忆写断言。凡本会话经 WebSearch 核实者在 `PROGRESS.md` 记条目与来源域；凡凭通识但未逐条复核者，明确标注「待核」。
- **三问过滤**：① 为什么是**现在**（触发事件/工具/数据成熟度）？② **势能**何在（人才流入、经费流向、顶刊密度）？③ 对本仓库**可介入**吗（有无公开数据/基准/软件/社区入口）？
- **锚点三元**：每条方向尽量给出「机构 + 关键人 + 可复用入口（数据集/基准/工具/期刊）」，缺一则诚实标注。

## 三、评估标尺 · Evaluation rubric

每条方向按五维打分（★，1–5），并给一句话判断：

| 维度 | 含义 |
|---|---|
| **前沿度** | 是否处在范式生成期，而非成熟应用期 |
| **势能** | 资金、人才、顶刊/预印本密度是否上升 |
| **可介入性** | 有无公开数据/基准/开源工具/社区，能让外部研究者真实参与 |
| **交叉杠杆** | 能否撬动本仓库其余模块（气候、遗产、语言、数理、阅读、思辨科学、跨文化经济） |
| **本地契合** | 与本仓库既有知识工程的自然衔接程度 |

> 分数是**决策辅助**，不是事实断言；每分附一句可证由，便于复核与推翻。

## 四、产物 · Deliverables

- `frontier_scan.md` — 侦察图 v1：六轴下的方向条目（含学者锚点、五维评估、合作切入点）
- `scholars.md` — 已核实学者名录：逐条回源的机构 · 代表作 · 回源锚 · 介入线索（frontier_scan 点名学者的佐证；含 Wikidata QID 回填）
- `references.md` — 一手文献清单：各方向代表作的 DOI / arXiv / PMCID（逐字照录命中原文，未确证者标 ◇ 待核）
- `entry_points.md` — 可复现介入入口：10 方向 × 公开数据/工具/基准 × 独立介入成本（🟢🟡🔴）× 本地模块接缝
- `PROGRESS.md` — 台账：每次检索的问题、命中来源、核实/存疑记录（可审计）

## 五、立场 · Stance

- **诚实标注边界**：学者名录、经费数字、机构归属随时间漂移；本文所有一时性事实带检索日期（2026-10-28），过期请以 `PROGRESS.md` 流程复跑更新。
- **发现 ≠ 背书**：列某方向/某人，不代表其结论正确，只代表其**当前值得注意**。事实与主张一律回一手文本。
- **迭代**：v1 是广度扫描；后续按用户兴趣把单条方向加深（学者深挖、代表性论文、可复现入口）。
