# 文化月旦 · Monthly Culture Review

> 双语文化梳评系列。每月一梳：读物、研究、影艺、舞台、声音。命名取《后汉书·许劭传》「月旦评」之义——每月初一品评，只梳当月最值得谈的作品。

## 凡例 · Conventions

1. **逐条回源**：每一条目均于编发当日以权威来源核实（✔ = 直接命中）；事实成立但一手机构/日期待核者标 ◇，下期设「订正」栏回看。
2. **第三语言精华引文**：凡涉中英之外语种作品，引原文最精华部分（公共记录之文本），配合中英双语解释；版权期内文本只存书名与自撰题解，不引正文。
3. **画龙点睛**：每期以「本月八点」收束——清单可忘，判断不可糊。
4. **诚实留白**：可回源材料稀疏的轴，宁缺毋滥；留白即刻度。
5. **采言四单（固定栏目）**：每期附四张拾单——金句、清醒事实、暖心、觉悟明心。句必归人，人必归源，源必归年：不为本月臆造任何句子；前人之句只因其本月重回公共耳中（获奖、致辞、转发）而入选，并注明原书年代；本仓自撰的引申一律标「本仓评注 / 阐释」，不混入引语。事实类条目须为当月发布或当月发生的可核事件，统计口径与基数年不明者标 ◇。
6. **站体一致**：单文件 HTML、离线可读、`zhzz-lang` 语言切换与站点总览共享，发布位置 `docs/culture_review/`。
