# 文化月旦 · Monthly Culture Review

> 双语文化梳评系列。每月一梳：读物、研究、影艺、舞台、声音。命名取《后汉书·许劭传》「月旦评」之义——每月初一品评，只梳当月最值得谈的作品。

## 凡例 · Conventions

1. **逐条回源**：每一条目均于编发当日以权威来源核实（✔ = 直接命中）；事实成立但一手机构/日期待核者标 ◇，下期设「订正」栏回看。
2. **第三语言精华引文**：凡涉中英之外语种作品，引原文最精华部分（公共记录之文本），配合中英双语解释；版权期内文本只存书名与自撰题解，不引正文。
3. **画龙点睛**：每期以「本月八点」收束——清单可忘，判断不可糊。
4. **诚实留白**：可回源材料稀疏的轴，宁缺毋滥；留白即刻度。
5. **采言四单（固定栏目）**：每期附四张拾单——金句、清醒事实、暖心、觉悟明心。句必归人，人必归源，源必归年：不为本月臆造任何句子；前人之句只因其本月重回公共耳中（获奖、致辞、转发）而入选，并注明原书年代；本仓自撰的引申一律标「本仓评注 / 阐释」，不混入引语。事实类条目须为当月发布或当月发生的可核事件，统计口径与基数年不明者标 ◇。
6. **站体一致**：单文件 HTML、离线可读、`zhzz-lang` 语言切换与站点总览共享，发布位置 `docs/culture_review/`。
7. **回源与声色**：每个域名都点开原文——能落到条目页的不落首页；站点拦机器而报 403/401/432/520 者，以浏览器能打开为准。古籍不附链接。
8. **图像与影音**：图像只取公有领域或已授权文件，转存本站并注明来源页与授权；声音与影像不转存，只指向版权人自己的页面。
9. **听读只念正文**：栏目名、日期、出处行、图注与第三语言原文一概跳过；语言一切换，朗读即止。声音两路——预生成自然声与本机浏览器语音，可切换。

## 重建音频 · Rebuilding the audio

听读的神经网络语音由 `build_audio.py` 预生成，成品是 `assets/audio/<音色>/<分节>.ogg`（Ogg/Opus，24 kHz 单声道 32 kbps）加一份句级时间轴 manifest（字节级插回 HTML 的 `/*AM-BEGIN*/ … /*AM-END*/` 之间）。

```sh
python docs/culture_review/build_audio.py            # 四轨全文
python docs/culture_review/build_audio.py --dry      # 只抽取队列并计量
python docs/culture_review/build_audio.py --pilot    # 单轨单节冒烟测试
```

队列取自页内朗读 JS 的字面移植（SKIP/READ/hidden/segs/clean/build 一一对应），所以音频里的一句与 DOM 里的高亮是同一个对象，按 `(blk, sub)` 定位。音色四路：中文晓晓、云希，英文 Ava、Andrew。

不机械的两处：一是**成段交付**——同一元素连续至多 600 字一次送入，语调上下相承，句级时间取自服务回送的 `SentenceBoundary`；二是**呼吸归置**——每段首尾静音削补至 0.05/0.40 s，段内停顿保留模型原样。全期实测：段内停顿 4814 处，均值 0.34 s（sd 0.14，最长 0.89 s）；元素交接（段间）604 处，均值 0.70 s。

本期规模：839 cues（zh 443 / en 396）→ 768 段，40 个 ogg，约 54.7 MB，四轨合计 234 分钟（单轨约 54–62 分钟；每轨按需分节加载）。缓存 `_audio_cache/<voice>/<sha1>` 附 sidecar 记录时长与句边界；短于 `expect_sec()` 一半的合成视为服务截断，删除重采，仍不成则退化为逐句重渲染——宁可节奏略平，不交一段空白。构建自带 `audit()`（本期为 0 处可疑高亮）；另有 `verify_audio.py` 独立复核：HTML 内联 manifest 与磁盘 manifest 一致、四轨 cue 覆盖 100%、每个 ogg 的解码时长与拼装时长相符。
