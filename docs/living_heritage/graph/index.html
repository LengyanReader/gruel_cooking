Graph as infrastructure

This page renders the project's knowledge graph directly from the database: corridors, heritage sites, scholars, and the relations among them. It is a management and maintenance surface — add, edit or delete nodes and edges in the data layer and this page updates automatically, with no code changes.

Corridor profiles

Each corridor carries its attached sites (belongs_to) and scholars (studies). Relations are stored in a dedicated edge table and resolved by locale at render time.
