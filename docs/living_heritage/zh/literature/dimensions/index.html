文献综述

综述即前行

本页是项目的前行与背景：一份经过逐条核实、带批注的综述，梳理那些为项目提供前提（关于流动、地方、物质生活、遗产与再生）的学者。它被设计成一份活参考——是后续脑暴、思想与观点梳理、以及进入实质研究的基础。完整带注书目见配套文档（materials/LITERATURE_REVIEW.md），其中已按研究问题做了逐条映射。

六维梳理

综述把每位涉及的学者放进六个维度来看。前提：物有能动性；行走生成知识；遗产服务于未来世代；变化是常态。视野：四副分析镜——行走与移动、物质性与物与废墟、遗产未来、连通与廊道。情怀：拥抱变化；善待衰败；尊重在地生计；对未来世代负责。方法：三步行走法、追踪一件事物、食物追踪、岛屿比较、数字民族志、叙事政策分析。实践：北京、哥特兰、南厄兰的田野循环与再生观察。人格：每位学者的学术品味、品质、精神、性格、关切与哲学——均从他们已核实的著作与机构站位中读出。

如何阅读学者肖像

以下肖像为学术人格速写［项目解读］，其依据是各学者已核实的著作与机构站位——绝不来自私生活或臆测。每幅肖像含六个维度：品味（他/她被什么吸引）、品质（学术上的长处）、精神（工作姿态）、性格（气质）、关切（让其夜不能寐之事）、哲学（更深层的信念）。代表作品按与本项目的相关度排序，并标注来源等级：［A］一手 / ［B］权威二手。

延伸学者圈

在五位核心学者周围，是一圈经核实的合作者与合著者：Þóra Pétursdóttir（《废墟记忆》；与奥尔森合著《理论在漂流》），Caitlin DeSilvey（《安排衰败》；姑息式看护），Sharon Macdonald（《记忆之境》；《遗产未来》），Rodney Harrison（《遗产：批判路径》；《遗产未来》主编），Anders Högberg（与霍尔托夫合编《文化遗产与未来》；《考古遗产管理没有未来吗？》），Jo Vergunst（与英格尔德合编《行走之道》），Gustav Wollentz 与 Samantha May（遗产未来方向合著者），Shanks–Webmoor–Witmore 三角（《考古学：物的学科》），哥特兰–拉帕努伊团队 Poort、Persson-Fischier、Elf Donaldson 与 Schaub，以及吉莱特的合著者 Emma Boyd、Elizabeth Bennett 与 Milena Arias Schreiber。
