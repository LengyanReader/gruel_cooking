方法论

让田野改变研究者

进入田野点之前，记录：我预期什么？田野工作期间：我实际观察到了什么？之后：我最初的理解中什么是错误的或不完整的？因此田野笔记本包含三个明确的类别——预期、观察、修正——以及另一个：意外发现。

三步行走法

步行A——研究者独自之行走。步行B——本地之行，与居民或长期居住者同行，问'这里最重要的是什么？'。步行C——实践者之行，与遗产、旅游、食物、考古、博物馆或地方政府从业者同行，问'外人误解此地什么？'。这些行走之间的差异本身成为数据。

追踪一件事物

在每一个田野点，选择一件有形的事物并追踪它——谷物、鱼、蔬菜、陶瓷、砖、盐、纺织品、一项手艺、一种食物。不要一开始就问这个物件意味着什么。首先问：它从哪里来？去哪里？谁触碰它？它的运输方式在哪里改变？谁赋予它意义？

追踪食物

食物是最有力的跨尺度追踪线索之一。一种食物可以连接：土壤/水源 → 生产 → 农民 → 道路 → 运河 → 市场 → 城市 → 家庭/餐厅 → 记忆/身份 → 旅游 → 未来可持续性。这也自然链接到厄兰岛的再生性遗产工作——考古土壤、植物和食物被用于探索过去如何生成新的生命。

范围纪律

大运河–丝绸之路关系：一条分析透镜，而非一个独立的大历史项目。食物：关系的追踪线索，而非独立学科。旅游：揭示性当代语境，而非主要主题。AI：研究工具，而非项目身份标识。

北京、哥特兰与瑞典：文化延续、连通性、转型与再生
