田野工作

第一轮——北京沉浸

7–14天，探索什刹海–御河、通州、张家湾及运河门户环境。在田野中应用运河–丝绸之路透镜：什么到达了？什么离开了？转运发生于何处？什么发生了变化？路线改变之后什么留存了下来？

第二轮——哥特兰

7–10天，比较波罗的海岛屿语境——维斯比的汉萨同盟过去、里达奈斯的贸易联系、哥特兰的乡村与海岸。

第三轮——南厄兰岛

3–5天，在再生实验室——甘拉·斯科格斯比的铁器时代证据，以及'过去何时变得能够生成未来生命'的问题。

第四轮——林雪平

3–5天，考察金达–约塔运河景观——当一项基础设施失去其原始经济功能时，文化意义发生了什么变化。

第五轮——返回北京

研究逻辑是循环的：北京 → 意外发现 → 瑞典比较 → 修正理论 → 返回北京 → 检验。目标是构建一种世界能够迫使理论发生改变的研究实践。

田野观察

北京大运河

  • 漕路上的行船小神龛 2026-09-23

    档案记录 2026-09-23:妈祖信仰随漕运的海陆航路北上——元代于海河口的天津敕建天妃宫（「泰定三年作天妃宫于海津镇」）；清康熙二十三年（1684）改封「天后」；运河沿线的妈祖宫庙又与北方娘娘信仰互渗。读作日常纹理:粮船上的一角神龛、闸前的一次平安祈祷——移动的守护神,而非宗派。来源:方广岭 [B]；徐晓慧 [B]。

  • 走进北京的香道：妙峰山路 2026-09-23

    档案记录 2026-09-23:与运河「望塔即到城」相对照,妙峰山香道是「走进北京」的徒步方式——路旁设茶棚,香会按春、秋两香走会（2008 年国家级非遗；顾颉刚 1925 年调查开启中国民俗学首次田野）。非运河廊道,而是京畿行进界面对照:抵达京城的两种方式,一乘舟于塔下,一徒步穿行于茶棚之间。待实地行走复核（升级为 walk/ritual）。

  • 元运河尽头的信仰 2026-09-23

    档案记录 2026-09-23:积水潭已核验为元代漕运粮船的终点港,什刹海段为全国重点文保（2013 年第七批）。火德真君庙与广化寺均为北京市第三批（1984）市级文保。田野中的悬而未决之间:广化寺的腊八施粥（至迟 2017 年有记录）今日是否仍在进行——2025 年北京日报舍粥名单未见广化寺;待现场复核。来源:北京市西城区政府 [A]；北京市文物局 [A]。

  • 大运河北端的塔 2026-09-23

    档案记录 2026-09-23:燃灯塔（始建北周 557 年；现存塔基为辽代；塔身于康熙三十五年 1696 年按原样重建）已核验为大运河北端标志——「三望燃灯塔，便到通州城」。文庙、佑胜教寺与紫清宫呈「品」字形布列,即通州「三庙一塔」。八角十三层密檐砖塔、高 56 米、风铃 2248 枚:此处视为日常航行的航海标,而非教义对象。来源:北京市民宗委 [A]；北京市政府 [A]。

  • 码头市镇失落的香火 2026-09-23

    档案记录 2026-09-23:张家湾作为「漕运移民市镇、多元信仰」的说法至多停在 [C] 级;就地关帝庙、龙王庙或河神庙,未找到任何可靠的存留证据。缺证本身就是田野结论:此镇的信仰景观如今只能经由它的早市与进行中的运河门户更新被阅读,而非经由站立的香火。待实地行走复核（升级为 walk/ritual）。

  • 网格里的闸 2026-07-09

    澄清上闸被保留在现代城市网格之内;街图之下的运河两岸排列着再造的遗产。此间的活态遗产,在日常生活与展示之间被演出。

  • 旧粮码头的粥 2026-07-02

    张家湾,漕运古码头:码头仍保持旧时走向,而近水早市已开张;粥摊在当年粮船停靠的人群中营业。

  • 可步行的运河 2026-06-28

    通州,拂晓:晨跑者与秧歌队沿着大运河公园移动,博物馆则在重建 1920 年代的纤道。运河被双重活化——既是日常设施,又是被展出的遗产。

  • 粮食由水路而来 2026-06-12

    后海—御河,清晨:水闸仍承载着漕运粮船的集体记忆。何来、何去、何处中转、何者改变。

哥特兰

  • Ridanäs 不在暂定名录 2026-09-11

    档案记录 2026-09-11:瑞典 UNESCO 暂定名录现仅有唯一一项（The Rise of Systematic Biology, 2009）；Ridanäs 不在其中。此前的维基说法已撤销，站点描述已更新。

  • 出口港的鲱鱼 2026-08-11

    弗勒耶尔港,维京时代曾从这里运出货物:如今同一处海湾的鲱鱼在码头边直售;一船一船,食物廊道登岸了。

  • 城墙的第二生 2026-07-19

    维斯比,沿城墙环行:十三世纪城墙如今缓冲着酒店与旅游大巴;城墙被保持原真,其背后的生活却在为旅游业被重新发明。

南厄兰岛

  • 南厄兰遗产边界包含 Gamla Skogsby 2026-09-11

    档案记录 2026-09-11:UNESCO WHC 968（准则 iv、v）核定面积 56,286 公顷——已确认遗产范围自 Karlevi 至 Gårdby 并延伸向南（2024 年 46COM 8D 澄清），Gamla Skogsby 位于遗产区内。

  • 从灶台到未来的谷物 2026-08-28

    Gamla Skogsby,就 2021 季厨房遗存而言:猪骨、磨石与陶器被解读为一个首领之家的记录;从灶台下取出的土壤正被重新种上传统谷物。

  • 当过去长出新生命 2026-08-04

    Gamla Skogsby 铁器时代遗址:以土壤、植物与食物追问——过去能否生长出未来的生命。

林雪平 / 金达运河

  • 以「活态」为出发点：金达运河 2026-09-11

    档案记录 2026-09-11:kindakanal.se 确认此水道自 1871 年起持续作为重要通道（15 座手控船闸、约 80 公里）；不存在官方「活态遗产」认定——此处「活态」是本项目的前提，而非对既有身份的断言。

  • 当运河成为风景 2026-09-02

    Nykvarn 闸,罗森湖:闸门管理员兼任导游,货驳载着观光客,国家利益保护把这条 1871 年的水道保存为文化风景。
