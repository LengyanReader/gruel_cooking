Tongzhou Canal · Field Basemap

A multi-layer working map centred on the Ran Pagoda — Green Heart trio — Zhangjiawan wharf triangle. Click a “档” marker to open each point's dossier (Evolution / Contact / Influence), every line tagged with source and grade. Beside the timeline, historical plates (1875 / 1907 public-domain scans) open as records: lacking registration control points they are never overlaid on the basemap. The channel appears and disappears by year: course differences are stated as status (navigable / abandoned / palaeo-channel / extant) and no unpublished palaeo-channel is reconstructed; places named in the sources yet lacking a verifiable position (Datongqiao, Gaolizhuang at Tongzhou) stay as text and are never plotted. Basemap tiles need a network; vector layers keep working offline. Every point carries a trust tier: OSM-verified or approximate anchor.

Offline: basemap tiles unavailable — vector layers (water, parks, points, layer toggles) still work.
