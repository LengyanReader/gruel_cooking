# 书单 · Reading Lists

> 独立书单系列（与「文化月旦」姊妹刊）：**收录外部机构开出的完整书单，逐条核到书目事实**。月旦梳的是当月最值得谈的作品；「书单」则把一份外来的货架整体接住——每一条都要落到出版社条目页或权威书目源，补足脉络与出处，促销与营销话术一律剥除。

## 体例 · Conventions

1. **一期一单**：一份外部机构书单做一期，文件名 `<yyyymm>-<来源>.html`；期号按月记。
2. **逐条回源**：每书落至出版社官网条目页或权威书目记录（ISBN/页数/出版日）；对爬虫报 403/401 的站点以浏览器口径收录并注明（站规第 8 条）。
3. **双语卡**：每卡四层——题解（事实出自原文推送与出版社页）→ 书单按（本仓一句评）→ 学者荐语（原推送所引，注明出处）→ 回源行（✔ + 当日日期）。
4. **诚实缺口**：原单与本核的任何出入（条数差、年份缺、译名自拟、促销口径）一律写进该期「编者按/方法」栏，不静默修正。
5. **不转存版权内容**：封面图、目录、正文引文在版权期内不转存；只记书目事实与公开书评出处。
6. **无音频**：听读是「文化月旦」月刊的固定栏目，书单不设。
