# societal — First Principles of Society

Using first principles to explain human social phenomena.

## Possible Starting Points

- Incentives and behavior: why do people respond to incentives?
- Trust and cooperation: emergence of cooperation in repeated games
- Information asymmetry: first principles of market failure
- Institutions and path dependence: how history locks in the present
- Network effects: how individual behavior produces collective patterns

## Format Requirements

Each principle file includes:
1. **Phenomenon**: the observable phenomenon to explain
2. **Principle**: the first principle used for explanation
3. **Derivation**: reasoning from principle to phenomenon
4. **Metathinking**: why does this principle hold? What assumptions does it rely on?
5. **References**: traceable sources
