# earthly — First Principles of the Earth

Using first principles to explain terrestrial and climate phenomena.

## Possible Starting Points

- The greenhouse effect: radiative balance and atmospheric composition
- Climate cycles: Milankovitch cycles and orbital parameters
- Geological timescales: plate tectonics and Earth's thermodynamics
- Self-organization of ecosystems: feedback loops and emergence
- The chaotic nature of weather: boundaries between determinism and predictability

## Format Requirements

Each principle file includes:
1. **Phenomenon**: the observable phenomenon to explain
2. **Principle**: the first principle used for explanation
3. **Derivation**: reasoning from principle to phenomenon
4. **Metathinking**: why does this principle hold? What assumptions does it rely on?
5. **References**: traceable sources
