# heavenly — First Principles of the Heavens

Using first principles to explain astronomical and cosmological phenomena.

## Possible Starting Points

- Gravity from mass: why does it follow $1/r^2$ decay?
- Light propagation and observation: why do we see celestial bodies as they were in the past?
- Orbital mechanics: the symmetry behind Kepler's laws
- Cosmic expansion: a first-principles derivation of Hubble's law
- Stellar evolution: the tug-of-war between nuclear fusion and gravity

## Format Requirements

Each principle file includes:
1. **Phenomenon**: the observable phenomenon to explain
2. **Principle**: the first principle used for explanation
3. **Derivation**: reasoning from principle to phenomenon
4. **Metathinking**: why does this principle hold? What assumptions does it rely on?
5. **References**: traceable sources
