# core — First Principles & Metathinking

This directory collects fundamental principles used to interpret phenomena across heaven, earth, and society, along with metathinking on *why these principles hold*.

## Subdirectories

- `heavenly/` — First principles for interpreting "heaven" (astronomy, cosmology, observable celestial bodies)
- `earthly/` — First principles for interpreting "earth" (climate, geology, ecology)
- `societal/` — First principles for interpreting "society" (behavior, institutions, economics)
- `metathinking/` — Metathinking: why do these principles hold? What are their boundaries?

## Working Method

1. Choose an observable phenomenon
2. Find the simplest principle that explains it
3. Ask: why does this principle hold? What are its assumptions? Where does it break?
4. Record the reasoning chain and knowledge genealogy
