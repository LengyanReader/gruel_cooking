# proof_narratives — Proof Narratives (证明叙事)

Proofs retold as stories anyone can follow — the house creed in practice: **math is never a difficult thing**; when a proof feels hard, the exposition has failed, not the reader.

Each narrative follows one arc:

1. **The puzzle** (谜题) — the question, made concrete.
2. **The false starts** (失败的起点) — what people tried, why it failed, the dead ends shown as part of the road.
3. **The key idea** (关键一步) — the one idea that unlocked it, motivated, not leapt.
4. **The click** (豁然开朗) — why it all fits, and what still remains.

A `Postscript` guards against the story being misread, and `Sources` follow the folder source rules.
