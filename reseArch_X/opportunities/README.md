# opportunities/ — 机会档案

每文件一条机会（一个岗位/项目），文件名 = 档案 `id`：`RX-<type>-<机构slug>-<yyyymm>.md`。
子目录按岗位类型：`phd/`（博士项目与个体博士职位）、`ra/`（研究员/研究工程师/RA）、`postdoc/`、`professor/`（教职与 PI 招聘）。
Fellowship / 访问学者等荣誉入口并入与其作用最相近的类型，在档案 `type` 里区分。

模板见 `../_template_opportunity.md`。纪律照 `../README.md` 第四节：
✔ 只给官方发布页核实过的条目；周期外推一律 ◐；状态漂移时**更新档案并在 `../scan_log/` 记一笔**，不静默删除。
