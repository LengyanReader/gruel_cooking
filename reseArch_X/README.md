# reseArch_X · 科研机会与开放学者检索评估

> 目的：全面检索高校、研究所及同等机构**已发布或即将发布**的研究工作与岗位（PhD / RA / postdoc / professor），
> 并在当前 AI 环境（2026）下回答两个问题——
> ① 哪些项目还值得申请、值得把几年生命投进去，做的是**真正有意义的工作**；
> ② 哪些学者**眼界开放、有真知灼见**，值得主动发起合作交流。
>
> 本模块是「机会层」：把 `academic_research/` 的方向图落到**具体的人、岗位与入口**。

---

## 〇、立场 · Stance（用户 2026-10-29 确立，本模块的最高准则）

**不走「海投申请流水线」。** 关心的次序是：

1. **谁在做什么有意义的工作**——卓越而开明的导师，以及**有潜力的新人**（早期职业、方向对路者，与名家同列为一级目标）；
2. 若某人的工作值得，**先做一个 MVP**（一件小而有真实的可交付物：一次复现、一份数据审计、一篇对话式短文），用它**开启专业对话**；
3. 借工作建立**相互了解**，再看有无机会**合作 或 受教**（受教＝被指导、访问、共事、长期问学——都算正当结果，甚至永远不申请，也自有其价值）。

由此派生的纪律：
- **时间线不强调**：届期/截止只作跟踪字段，不作驱动理由；错过一季不是损失，对话本身才是资产。
- `shortlist`/`contacts` 的排序标准从「哪值得申请」改为「**哪值得先做 MVP 去对话**」。
- 每位导师档案的核心不是招生页，而是 **`current_work`（他此刻在做什么，回源带日期）→ `mvp`（我们能造什么去接话）→ `dialogue_hook`（一句不带索取的真实话柄）**。
- **话柄 MVP 的宽度（用户 2026-11-04 批评修订）**：MVP 不是「一页小账+请您判」的求批便条——必须是一件**能立住（有真实数据/文本/成品撑底）、能公开（拿出来即可读可用，不靠私人通信语境）、能让多位学者进同一场对话（场景而非私信）**的作品。`dialogue_hook` 是这件作品的公开说法，不是请求裁决的私信。v5–v7 档中「单人小账」形态的话柄记为**该场景作品的个人入场版**，发起对话前逐档升级为场景版；场景层登记在 `indexes/dialogue_map.md` 「场景作品」节。
- 衡量「开明」看**行为**：是否公开数据集/开放方法、是否支持学生一作与跨界、是否把「谁算知识生产者」敞开（详见第三维）。
- **感受性评估（用户 2026-11-04 指令加入）**：每位导师另登四项美德——**悟性 / 人格 / 性格 / 慈悲心**（schema 字段 `v_insight / v_character / v_temperament / v_compassion`，另有总评 `v_overall`）。口径必须诚实：公共材料**触不到私密人格**，故此项不作事实断言，只作**感受性判读（一律标 ◐；无痕迹即写「痕迹不足 ◇」，禁止形容词填充）**。每档须锚回本文件内已溯源的行为痕迹（why_open 的开放数据、risk 的指导生态观察、what_real 的反驳方式、current_work 里对弱者/非人的关切位置等）。判读三档：**显现良善**（≥2 处独立行为痕迹同向）/ **倾向良善**（痕迹单向或稀疏）/ **痕迹不足**（不作评）。受教/合作是长期共事，识人先于识文——此项与 `current_work` 同权重进对话地图的判读，但不进「事实」层。
- **连接闸口（用户 2026-11-04 指令加入，学者/新方向入库的准入条件）**：值得连接的工作必须同时——① **有价值**：面对真实问题，去掉热点词问题仍成立；② **有人情味**：关切具体的人与生活，不是制度指标游戏；③ **直面时代**：在对 AI 变局、文明转型等时代真问题**当下处理**，而非绕开；④ **严格避免学术垃圾**：方法内卷、去掉 AI 词仍是老问题、无真实受众的空转——一律不入库。连接对象是**人格光辉（四项美德有显现良善痕迹）且切实实践（不止于写论文——在建机构/工具/课程/政策）**的人。此闸口同时管**新学者、新轴、新方向**的准入：宁可少不可滥，名气大不够格者不进，进了的每档都要过此闸。

## 一、与既有模块的接缝 · Seams

| 模块 | 回答 | 本模块如何承接 |
|---|---|---|
| `discovery_atlas/`（science 域） | 去哪儿**找**（基础设施） | 复用其来源注册与 probe 惯例 |
| `academic_research/` | 什么**值得追**（方向 × 势能 × 可介入性） | frontier_scan 与 scholars 点名的方向/学者，在此展开为职位档案与导师档案 |
| `docs/culture_review/` | 当月文化动态 | 学界人事、重大资助、奖项公告可作线索来源之一 |

本模块补上缺的最后一问：**人往哪里去**（where does a person actually go）。

## 二、抓取范围 · Coverage

- **机构**：高校（含非 G14 的新秀与地区强校）、公立/私立研究所（Max Planck、CNRS、KAIST、中科院各所、艾伦研究所…）、交叉机构与独立实验室（Santa Fe、MATS、Konrad Zuse、Allen AI…）、企业研究院的学术化项目（FAIR、OpenAI Residency 之类）。
- **岗位**：PhD（含结构化博士项目、DTP/LITE 之类）、RA / 研究工程师 / 研究员、postdoc、教授/PI 教职（含 tenability 观察）、以及荣誉性入口（访问学者、fellowship、resident、visiting student）。
- **「可能发布」**：周期性招生项目按上一周期外推，一律标 ◐；未公开但按导师资助到期、组内节奏可合理预期的，记入 watchlist 并标 ◐，**绝不写成已存在的事实**。

## 三、评估标尺 · Six-dimension rubric（★1–5，每分附一句可证由）

| 维度 | 问题 | 证据来源 |
|---|---|---|
| **真问题性** | 去掉 AI 热点词后，这个问题本身还成立吗？产出是理解还是 benchmark 增量？ | 项目页原文、近 3 年组内发表的实际问题 |
| **AI 暴露度** | AI 进步让这个项目**增值**（判断、数据、现场、品味稀缺）还是**贬值**（生产环节可被替代）？ | 工作内容分解、领域自动化文献 |
| **导师质量** | 近 5 年：组内 PhD 中位毕业年限、去向、师生合著生态、独立指导 vs 放养/压榨 | 学术谱系（Mathematics Genealogy / 博士论文致谢页）、 alumni 页 |
| **资源与稳定性** | 资助来源与期限（ERC / DFG / NSF-CORE / 青基…）、计算与数据条件、组规模 | 资助公告、项目页、OSF/GitHub 活跃度 |
| **可及性** | 对「我」的申请画像的匹配与竞争面：签证/语言/经费通道/届期 | 招生页硬条件、往年录取观察（观察≠事实） |
| **眼界开放度** | 跨域接纳、允许失败、真名对话——决定「真正合作交流」是否可能 |  writings、演讲问答、对学生跨域流动的事后支持 |

**判断口径**（只记可核行为，不做人身评价）：
- 绿灯信号：导师支持学生独立署名一作、组内成员跨界后仍被引用合作、对失败实验公开复盘、招生写明"问题优先于方法"。
- 红旗信号：单年批量招生无经费来源、组内 PhD 延期率异常、把 LLM 微调当全部贡献、只回模板邮件、以 group list 替代个人面谈。

## 四、标记与纪律 · Marks & discipline

沿用仓库铁律（`harness/`、memory：zero-fabrication）：

- ✔ **命中** — 官方发布页/公告原文核实，带发布或检索日期；
- ◐ **预告/外推** — 周期推断、资助到期推断、传闻，注明推断依据；
- ◇ **待核** — 事实倾向存在但一手来源未落地，回源后升级；
- 撤回与更正照 ledger 惯例记入 `scan_log/`，不静默删改。

一时性事实（届期、薪酬、名额）随时间漂移：**每条档案带 `asof` 日期**，过期只允许复跑更新，不允许凭记忆续写。

## 五、数据模型 · Schemas

### opportunity（每文件一条，落 `opportunities/<type>/`）

```yaml
id: RX-<type>-<机构slug>-<yyyymm>
type: phd | ra | postdoc | professor | fellowship
institution:
country:
program:
pi:                # 或 hiring-committee
application_url:
deadline:          # ISO 或 "rolling" / ◐外推
funding:           # 薪酬/tuition/经费来源，能写数字才写数字
status: ✔ | ◐ | ◇
asof: YYYY-MM-DD   # 本条最后回源日期
dims: {q: , ai: , m: , r: , a: , o: }   # 六维分值，缺维写 "?"
verdict: 一句话（值得申请 / 值得先建立联系 / 观察 / 不投）
sources: [ url1, url2 ]
```

### scholar（每学者一卡，落 `scholars/`）

```yaml
name:
affiliation:        # asof 有效，机构漂移要重核
tier: 卓越开明 | 有潜力   # 二者同为一級目標
field:
homepage:           # 官方主页链接（面板直点即用）；不嵌学者肖像——合成/第三方图片一律不用
ethos:               # 内在情怀：对知识/社会的底层立场（引原文，带出处）
vision:              # 愿景：他/她想把领域推向何方（引原文，带出处）
theory_practice:     # 理论与实践结合：具体的软件/工具/实验努力（✔ 事实，带链接）
current_work: 他/她**此刻（当年）在做**的有意义工作（回源，带日期与出处）
trends:              # 动向与分析：近 6 个月的具体变化与潜在趋势分析
why_open: 眼界开放的**可证行为**（不是形容词）
what_real: 其"真问题"表述（引用其原文，标明出处）
mvp: 一件**能立住、能公开、多位学者可进同一场对话**的作品规格（复现/审计/公开短文/可看的数据切面——非求批便条，2026-11-04 口径）
dialogue_hook: 这件作品的公开说法，一句不带索取（从 mvp 自然长出来）
mode: 合作 | 受教 | 两者    # 期望的后续形态（受教＝被指导/访问/问学；合作＝对等共事）
entry: 后续入口（workshop / 访问 / 联合申请）——只在对话成立后才启用
risk: 近年指导生态观察（不作人身评价）
v_insight: 悟性·感受性判读（显现良善|倾向良善|痕迹不足 + 行为痕迹锚，◐）
v_character: 人格·感受性判读（同上口径）
v_temperament: 性格·感受性判读（交锋/容错方式，同上口径）
v_compassion: 慈悲心·感受性判读（对弱者/边缘/非人的位置，同上口径）
v_overall: 总评一句 + 证据边界（公共材料≠私密人格）
# —— 以下八项为「介绍增维」（用户 2026-11-04 指令：每人再加维度、更详实具体，同时突出重点）——
essence: 一句话要点——为何值得连 + 最硬的一条已核实证据（渲染置顶，作「重点」）
key_works: [代表作清单，书名/文 + 年份 + 出版处（仅从已核实 current_work/trends 重抽，不新增主张）]
repo_anchors: [与本仓的具体文件/模块接口（只写 grep 核过的真实路径）]
circle: [学术圈子·人际网络节点（机构/学会/会议圈/关键合作者（本库外）/思想脉络；只从已 ✔ 内容重抽，不新增事实主张）]
peer_bridges: [与已入库学者的对话连线（同场场景/承接，从 mvp/v_overall 抽）]
why_now: 时代抓手——让「此刻」成为时点的 2025-26 具体事件/出版物
entry_sequence: [分层触达次序：公开作品 → 会议/机构 → 私信（从 entry 展开）]
feasibility: 可达性·回信可行性/带宽评估（诚实，多为推断标 ◐）
open_questions: [待追问的诚实缺口清单（归拢现有 ◇/◐ 待补项）]
stamps: [ ✔/◐/◇ + asof ]
```

## 六、产物 · Deliverables

- `scholars/` — 开放/有潜力学者档案（核心：current_work → mvp → dialogue_hook）
- `mvp/` — 一件件小而有真实的可交付物规格（对话的引子；做完即成作品集一页）
- `opportunities/{phd,ra,postdoc,professor}/` — 机会档案（每文件一条，可 grep 可 diff）—**降为跟踪副产物，非驱动目标**
- `indexes/dialogue_map.md` — 对话优先名册（谁在做什么 → MVP → 话柄 → 进展）—**本模块主视图**
- `indexes/shortlist.md` — 机会排序（保留，但时间线弱化、verdict 口径改为「值得先做 MVP 对话」）
- `scan_log/` — 检索台账：每轮的 query、命中、来源域、核实记录（可审计）
- `web/build_reseArch_X.py` + `web/template.html` — **调研面板生成器**：从上述所有源重生一份只读仪表盘 `docs/reseArch_X/index.html`（对话名册 / 学者卡片 / 方向轴覆盖 / MVP 轨道 / 机会档案 / 六维标尺 / 调研日志 / 新方向登记）。定期调研→分析→评估→加新轴的工作循环，界面入口在此。`.md` 是唯一事实源，页面每次重生不手改。详见 `web/README.md`。
- 方法论变更须同步修订本 README 并记台账

## 七、启动路线 · Roadmap

1. **v0**：框架落地——目录、标尺、schema、README。
2. **v1 广扫**（已跑，见 `scan_log/`）：AI/数据 × 人文各轴的机会档案 + 学者锚点回源。
3. **v1.5 转向对话优先**（用户 2026-10-29 指示）：为「卓越开明 / 有潜力」的导师补 `current_work`（当年在做什么）、`mvp`（我们去造什么接话）、`dialogue_hook`；产 `mvp/` 首件规格与 `indexes/dialogue_map.md`。时间线与申请材料退居次要。
4. **常态**：追踪各位导师的工作进展（新论文/新数据集/新报告），每有一次足以对话的进展，就动一件 MVP；**不追 deadline，追对话**。
