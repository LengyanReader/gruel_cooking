# mvp/ — 对话用的小可交付物

> 立场（`../README.md` 第〇节）：不做海投。每件 MVP 是**一件小而真实、可公开的东西**，
> 用来接住某位导师**当前的工作**，把专业对话打开——做完即成作品集一页，对话不成也自有其价值。

每件 MVP 规格须含：**接谁（学者档案链接）· 输入（本仓哪份数据 / 对方哪个方法）· 做什么 · 产出形态 · 为何足以引发对话 · 成本估计**。
命名 `MVP-<nnn>-<slug>.md`。做完在文件顶部把 `status: planned → built`，并在 `../indexes/dialogue_map.md` 更新进展。
