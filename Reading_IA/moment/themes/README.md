# themes/ 持久思潮档案

Dossiers for cultural movements and thought trends that **outlive any single window**. A dossier is updated whenever the theme moves; briefs drain into it.

记录**跨越任何单一时窗**的文化运动与思潮的档案。主题一动，档案即更新；简报成熟后并入其中。

## Lifecycle 生命周期

```
brief (趁热) → series window (归窗) → dossier (沉淀) → category/lead 反向回阅读 (输回阅读)
```

A theme may eventually earn a place in `readings/categories/` (moment-layer ring) — that is the highest honour, read and trend fused.

主题最终可能升入 `readings/categories/`（时事层）：读到与趋势合一，此为上境。

## Template 模板

```markdown
# <theme> 思潮档案 · Dossier
status: active | folding | dormant

## Thesis 一句话论题
（这个思潮在说什么？一句话。）

## Lineage 谱系
（它从哪里来：old idea → mutation → now。连 readings/relations/）

## Carriers 承载者
（实验室 / 出版方 / 智库 / 平台 / 人物）

## Recent movement 近期走势
（按时间倒序 append 最新动态，注明 provenance）

## Opposing currents 对立潮
（谁会反对它？反叙事是什么？）

## Open questions 开放问题
（2–3 个问题，既是档案之问，也是阅读延伸线索）
```
