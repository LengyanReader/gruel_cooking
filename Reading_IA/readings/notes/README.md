# notes/ 读书笔记

The live record of reading. One note per book, filed by book slug: `notes/<book-slug>.md`. Notes capture the **process**, cards capture the **result**.

阅读的现场记录。一书一记，按书名代码归档：`notes/<book-slug>.md`。笔记记录**过程**，卡片提炼**结果**。

## Template 模板

```markdown
# 《书名》 笔记 · Note

- **book**: [[library/YYYY-slug]]
- **read**: YYYY-MM — YYYY-MM
- **form**: 精读 close / 通读 skimming / 选读 select / 弃读 dnf
- **domain**: #tag（如 #mathematics #theory #medicine-health）跨学科检索用
- **echo**: [[categories/<slug>]] 原型·概念簇挂钩

## 高光 Highlights
> （引用 + 一行动态 reply）

## 眼前一亮 What struck me
（新概念、新连接、措辞的妙处）

## 不同意 What I disagree with
（记录为什么——不同意是最快的思考入口）

## 回响 Echoes
（唤起哪些旧读、哪些 moment/ 思潮档案、哪些延伸线索）
```

## Margin rules 批注纪律

- Quote **short**, respond **long**. 引用要短，回应要长。
- Disagreement counts as progress. 不同意即进步。
- One echo minimum per note: always write down at least one thing the book made you remember or want to read next. 每条笔记至少一个回响，逼出延伸。
