# Author card template v2 作者卡片模板 v2

One file per author / writer / thinker. Naming: `surname-given.md`. **The 知识图谱 is the point of this card:** who shaped them, their contemporaries/friend-circle, collaborators, school, critics. Every factual claim carries a confidence mark (`✓/◐/○/✗`) and a 出处 link — sources go first, always.

```markdown
## 作者卡片 · Author Card

- **name 姓名**: 中文名（原语名 / native name）
- **era 时代**: birth–death / active
- **nationality 国籍** / **birthplace 出生地**:
- **domain 领域**: 学派与学科
- **anchors 机构**: 教育 / 机构 / 出版社 / 所属
- **native language 书写语言**:
- **awards 奖项**: year · 奖（✓ 已核）

> 出处 provenance: 生平/奖项/机构 各来源链接 + 把握标注

### 生平轨迹 Timeline
| 年份 | 事件（教育 → 转折 → 成名 → 现况） | 把握 |
|---|---|---|

### 知识图谱 Knowledge Graph
- **受谁影响 / 学统源头**: …（一句理由 + 来源）
- **同代人 · 朋友圈**: 同行 / 编辑 / 译者 / 对谈者 / 合作圈（每位配一句角色）✎ 合著另列
- **传人 / 影响谁**: …
- **批评者 / 论争**: 关键批评者与论点
- **流派归属 School**: …（一句理由；如「法国 néo-polar」「见证文学」「在宅緩和ケア 话语场」）

### 立场与一贯关切 Stance
（反复回应的问题；母题；1-3 句）

### 实际阅读进度 Read status
（真正读过哪些，状态如何；未读另算）

### 为何此刻 Why now
（与 moment/ 档案的关联；为何现在读）
```

Add a row to the author graph after writing: `relations/authors_graph.md`（节点属性 + 边一行一条）。
