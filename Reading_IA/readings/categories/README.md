# categories/ 分类与主题体系

A category is a **persistent theme cluster** — not a rigid shelf. Categories should be few, memorable, and cross-cutting; the same book can claim several.

分类 = **可持续的主题簇**，而非僵硬的分类架。分类应少而好记、彼此交叉；同一本书可归属多个分类。

阅读范围是**全领域**的——不限于文学。人文、社科、科学、数学、哲学、跨学科皆在窗内。「领域」是横轴（学科标签），「分类」是纵轴（主题簇），两者正交。

---

## Design principles 设计原则

1. **From the text, not the library** — categories grow out of the reading itself, not an external scheme. 分类从阅读本身长出，而非外部体系。
2. **Sparse** — begin with ~8–12; split only when a cluster has grown dense. 起步 8–12 个；簇变密才细分。
3. **Cross-cutting by design** — a category should light up books from different shelves, schools and disciplines. 分类应为交叉而生，照亮不同书架、学派与学科角落的书。
4. **Layered — three rings 三层环**：
   - **Concepts 概念层**（主题簇 + **原型/母题/深层模式**）：`limits-of-knowledge`, `mirror-double 双身与反生活`, `aftermath 余波叙事`, `aestheticized-violence 图像化暴力`…
   - **Traditions 传统层**（学派 · 文艺理论 · 文明脉络）：`continental-philosophy 欧陆哲学`, `french-neopolar 法式新黑色文学`, `testimonial-lit 见证文学`, `structuralism 结构主义及其后`…
   - **Moment 时事层**（live clusters driven by `moment/`; these come and go）：实时驱动态簇，随思潮来去。
5. **A domain axis beside the theme axis** — see below. 主题轴之外另有领域轴，见下。
6. **Every category needs a one-line thesis** — if you cannot state it, merge it. 每个分类需一句话论题，讲不清就合并。

## Placement rulings 放置裁定（文艺理论 · 文学原型 · 文化模式）

| 内容 | 归属 | 理由 |
|---|---|---|
| 文学原型 / 母题 / 深层模式 | **概念层 · 原型簇**（命名上明示「原型」） | 原型是跨文本/跨学科的主题簇的极致形态——它天然是被多次照亮的簇 |
| 文艺理论 / 学派（结构主义、法兰克福、叙事学……） | **传统层** + **作者卡**（理论家也是人：Propp/Frye/Barthes） + `relations/` 师承·反驳边 | 学派是传统簇；理论家是思想的坐标；师承是显式边 |
| 文艺理论的概念工具（聚焦、陌生化、互文、mise en abyme……） | **_概念层** + **术语架 `glossary.md`** | 概念工具比簇更细——用术语卡承载「定义+出处」 |
| 文化模式（文明如何自我叙事） | **概念层 / 传统层 双栖建档**；活跃者升 `moment/themes/` | 模式=深层结构，思潮=表层波形；档案与动态联动 |

**原则总结**：原型进概念层并**显式命名**；理论进传统层、理论家进作者卡、理论工具进术语架；模式双栖于阅读层与思潮层。三者都**不需要新的顶层卡片**。

## Domain axis 领域轴（开放标签 · open tags）

Backbone for "what kind of knowledge is this". Not a shelf, not a hierarchy — a tag axis orthogonal to theme clusters. Reading covers all of it.

领域轴回答「这是什么学科的知识」。它不是书架、不是层级，是与主题簇正交的开放标签。人类阅读的视野全领域覆盖。

| 领域 tag | 中文 | 例 |
|---|---|---|
| `literature` | 文学（虚构/诗） | 小说、诗歌、戏剧 |
| `theory` 文艺理论 | 文学批评与理论 | 叙事学、结构主义、接受理论 |
| `philosophy` | 哲学 | 认识论、伦理、美学 |
| `history` | 历史 | 思想史、社会史、文化史 |
| `social-science` | 社会科学 | 社会学、人类学、政治学、经济学 |
| `cognitive-psych` | 认知与心理学 | 认知科、临床、社会心理 |
| `mathematics` | 数学 | 证明、结构、建模 |
| `physical-sci` | 物理与天文学 | 宇宙学、量子、经典力学 |
| `life-sci` | 生命科学 | 生物学、演化、生态 |
| `technology-ai` | 技术与 AI | 计算机、算法、信息时代 |
| `medicine-health` | 医学与照护 | 安宁医疗、公共卫生 |
| `cross-disciplinary` | 跨学科 | 双学科以上，正是本项目最爱的地面 |

## Glossary 术语架

Term-level records live in **`categories/glossary.md`** (single source) — the generator builds `docs/reading_ia/glossary.html`. Every term: 定义 + 出处 + 隶属簇 + 把握。数学/哲学/理论阅读中不断积累的新词，先落此处，成熟后升为概念层簇。

术语级记录存放于 **`categories/glossary.md`**（唯一来源），由生成器产出 `glossary.html`。每个术语带定义、出处、隶属簇与把握。遇到新词先落术语架，成熟后晋升为概念层原型簇。

格式见 `glossary.md` 头部。

## Card format 卡片格式

```markdown
## 分类卡 · Category Card

- **slug**: <category-slug>
- **ring 环**: concepts | traditions | moment
- **thesis 一句话论题**: 
- **domain 领域轴**: <open tags, optional>
- **related categories 相邻分类**: 
- **core books 核心书目**: [[library/<slug>]] × n
- **key authors 关键作者**: [[authors/<slug>]] × n
- **archetypes 原型典例**: ← if ring=concepts, name the master pattern here
- **live moment ties 时事挂钩**: links into `moment/themes/`

### 展开说明 Notes
（这个簇在争什么问题？分歧在哪？）
```

原型簇的卡片额外要求：写出**典例链**（同一原型在 ≥2 个不同文本/学科中的显影），这是「原型」区别于普通主题簇的判据。
