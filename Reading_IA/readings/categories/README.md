# categories/ 分类与主题体系

A category is a **persistent theme cluster** — not a rigid shelf. Categories should be few, memorable, and cross-cutting; the same book can claim several.

分类 = **可持续的主题簇**，而非僵硬的分类架。分类应少而好记、彼此交叉；同一本书可归属多个分类。

## Design principles 设计原则

1. **From the text, not the library** — categories grow out of the reading itself, not an external scheme. 分类从阅读本身长出，而非外部体系。
2. **Sparse** — begin with ~8–12; split only when a cluster has grown dense. 起步 8–12 个；簇变密才细分。
3. **Cross-cutting by design** — a category should light up books from different shelves. 分类应为交叉而生，照亮书架不同角落的书。
4. **Layered** — three rings: 三层环：
   - **Concepts 概念层** (e.g. limits-of-knowledge, information-as-mode)
   - **Traditions 传统层** (e.g. continental-philosophy, chinese-intellectual-history, pragmatism)
   - **Moment 时事层** (live clusters driven by `moment/`; these come and go)
5. **Every category needs a one-line thesis** — if you cannot state it, merge it. 每个分类需一句话论题，讲不清就合并。
